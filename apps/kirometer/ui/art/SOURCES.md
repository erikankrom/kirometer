# Kirometer listing artwork

The banner and card mascot uses the original ghost paths and mask from https://kiro.dev/icon.svg, retrieved October 1, 2026. Shape and eyes are unchanged; the purple app-tile background is omitted when placing the ghost on the illustrated screen. The source SVG is included as kiro-official.svg. Kiro artwork belongs to its respective owner; Kirometer is a companion project.

The duotone app icon uses the enclosure silhouette in a 24 × 24 viewBox. `icon-crew.svg` is the canonical source: `var(--ico-a, currentColor)` for structure and translucent fill, `var(--ico-b, currentColor)` for the usage accent, 1.8-unit outline and 1.4-unit details. This follows the bundled Notes, Dev Fleet, Research Lab, and Meetings SVG definitions inspected October 1, 2026.

Crew inlines only `/app-assets/<app>/<file>.svg`; externally installed app URLs use `<img>`. `scripts/build_app_icon.py` generates the inline module and explicit light/dark fallback images from the same source. Fallback colors match Crew's Kiro palettes (`--muted`: #5e5966 / #938f9b; `--accent`: #8e48ff). Image viewport media queries reproduce built-in icon insets in Library and Detail tiles without shrinking the sidebar icon. No inversion filters or extra purple screen fill. External images cannot inherit arbitrary user theme or hover tokens; the device-card inline SVG can.

Screenshots show the shipped crew-app/ui/index.mjs rendered by tests/ui/harness.jsx with illustrative sample data, in both light and dark mode.

Screen-gallery previews are generated by scripts/build_layout_previews.py using the firmware atlas from the licensed Spirit of Kiro assets. Previews use illustrative credits and dates; the actual device uses collected data.

Interaction audit: disabled Library tiles use grayscale and 45% opacity; enabled is distinct from selected. Hover/selected maps structure to --accent and detail to --text, with a 200 ms transition. External image variants cannot implement that parent-driven state change; this requires Crew renderer support. Inline fallback declarations use :where() to avoid overriding host state selectors. See DESIGN.md for the state matrix.

Library detail banners use Space Grotesk Regular and Bold from firmware/assets/fonts (SIL OFL 1.1). Text is converted to vector paths so Crew renders the correct typography without installed fonts. Regenerate both themes with scripts/build_listing_banners.py; editable templates live in scripts/artwork/.

October 2, 2026: library screenshots refreshed from the current UI harness in light and dark themes, showing the Devices grid and Screen gallery. Device identities, credits, and connection states are illustrative sample data; typography uses the bundled Space Grotesk fonts.
